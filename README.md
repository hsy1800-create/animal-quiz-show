# 🐾 동물 친구 퀴즈쇼 (웹앱판)

6학년 2학기 과학 「1. 계절의 변화 마무리하기」 PPT 게임(양송이샘 · 득템공방)을
학생들이 각자 기기로 접속해 함께 즐길 수 있도록 만든 웹앱입니다. 20~25명(최대 8모둠) 기준입니다.

- **선생님 화면** `host.html` — 전자칠판/TV에 띄워 진행 (방 코드·QR 표시, 채점, 보물 상자, 점수판)
- **학생 화면** `index.html` — 휴대폰·태블릿·크롬북으로 접속 (방 코드 4자리 + 이름 + 모둠 선택)

## 게임 흐름 (원본 PPT 규칙 그대로)

1. 문제가 나오면 각자 **개인 정답** 제출 → 맞히면 개인 1점 (절대 평가)
2. 모둠 친구들의 답을 보며 의논 → 한 명이 **모둠 정답** 제출
3. 선생님이 **정답 공개** → 자동 채점 (⭕/❌ 를 눌러 선생님이 바꿀 수 있음)
4. 정답 모둠은 **보물 상자 1~4번** 선택 → 상자 공개 (+10 / 기본 점수 / -10 / 아이템 상자 또는 꽝)
5. 아이템: 🎫 프리 패스 · ✨ 더블 포인트 · ⭐ 황금 별 · 🎲 복불복 주사위 · 🦝 점수 스틸 · 📋 점수 복사 · 🔄 점수 교환
6. 마지막에 황금 별 보너스(1개 50 · 2개 120 · 3개 200 · 4개 300)를 더해 모둠 순위 발표

## 바로 체험해 보기 (설정 없이)

`firebase-config.js`를 고치지 않은 상태에서는 **체험 모드**로 동작합니다.
같은 브라우저에서 `host.html` 탭 하나, `index.html` 탭 여러 개를 열면 서로 연결됩니다.
(실제 수업에서 여러 기기가 접속하려면 아래 Firebase 설정이 필요합니다.)

## 1단계: Firebase 설정 (무료, 10분)

1. <https://console.firebase.google.com> 에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됨)
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 을 **사용 설정**
3. **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: `싱가포르(asia-southeast1)` 추천
   - **잠금 모드**로 시작
   - 만들어진 뒤 **규칙** 탭에 이 폴더의 `database.rules.json` 내용을 통째로 붙여넣고 **게시**
4. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(</>)** 으로 앱 등록 (호스팅 체크 안 해도 됨)
5. 화면에 나온 `firebaseConfig` 값을 `firebase-config.js` 에 붙여넣기
   (`databaseURL` 이 없으면 Realtime Database 화면 위쪽의 `https://...firebasedatabase.app` 주소를 넣으세요)

> Firebase 웹 설정값(apiKey 등)은 공개되어도 괜찮은 값입니다. 데이터 보호는 3번의 규칙이 담당합니다.
> 무료(Spark) 요금제의 동시 접속 한도는 100명이라 한 반 수업에 충분합니다.

## 2단계: GitHub Pages로 배포

1. GitHub에서 **New repository** (예: `animal-quiz-show`, Public)
2. **Add file → Upload files** 로 이 폴더의 파일을 모두 올리기
   (폴더 안의 모든 파일)
3. 저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**
4. 1~2분 뒤 주소가 생깁니다: `https://아이디.github.io/animal-quiz-show/`
   - 선생님: `.../host.html`
   - 학생: `.../` (선생님 화면의 QR을 찍으면 방 코드까지 자동 입력)

## 수업에서 쓰기

1. 선생님이 `host.html` 에서 모둠 수·이름, 시작 아이템, 제한 시간, 문제를 고르고 **방 만들기**
2. 학생들은 QR 또는 주소 + 방 코드로 접속 → 이름 입력 → 모둠 선택
3. **게임 시작!** 이후 버튼 한 개씩 눌러 진행
4. 학생 기기가 부족한 모둠은 선생님 화면에서 대신 상자·더블 포인트를 누를 수 있어요
5. 진행 중 새로고침해도 **이어서 진행하기** 로 돌아올 수 있어요
6. 오른쪽 위 **점수·아이템 조정** 으로 점수와 아이템을 직접 고칠 수 있어요

## 문제 바꾸기

`questions.js` 에서 문제를 고치거나 추가하면 됩니다. 형식은 3가지입니다.

```js
{ type: 'short',  q: '문제', answer: '정답', accept: ['띄어쓰기 다른 정답', '비슷한 표현'] },
{ type: 'ox',     q: '문제', answer: 'O', explain: '해설(선택)' },
{ type: 'choice', q: '문제', choices: ['보기1', '보기2', '보기3', '보기4'], answer: 2 },
```

단답형은 띄어쓰기·괄호·전각문자를 자동으로 무시하고 채점합니다.
